# Server Inventory

This document defines the planned server infrastructure for RK Technologies Pty Ltd.

| Server Name | Role | Operating System | Description |
|-------------|------|------------------|-------------|
| RK-DC01 | Domain Controller | Windows Server 2022 | Primary Active Directory Domain Controller |
| RK-DC02 | Backup Domain Controller | Windows Server 2022 | Secondary Domain Controller for redundancy |
| RK-FS01 | File Server | Windows Server 2022 | Central file storage |
| RK-DHCP01 | DHCP Server | Windows Server 2022 | IP Address Management |
| RK-PRINT01 | Print Server | Windows Server 2022 | Centralized printer management |
| RK-MGMT01 | Management Server | Windows Server 2022 | Administrative tools and monitoring |
| RK-WSUS01 | Windows Update Server | Windows Server 2022 | Windows Update Services |
