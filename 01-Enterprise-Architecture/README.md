# Enterprise Architecture

## Project Overview

This project documents the design of the enterprise IT infrastructure for **RK Technologies Pty Ltd**, a fictional Australian Managed IT Services and Cybersecurity company.

The purpose of this project is to design a scalable, secure, and well-documented IT environment before deployment.

---

## Business Scenario

RK Technologies Pty Ltd is a growing technology company with offices in Newcastle and Sydney.

The company requires a secure enterprise network that supports:

- 120 employees
- Microsoft 365
- Active Directory
- Microsoft Entra ID
- Microsoft Intune
- Windows Server
- File Services
- Secure Remote Access
- Enterprise Security

---

## Project Objectives

- Design the enterprise environment
- Create documentation standards
- Define infrastructure requirements
- Prepare for Active Directory deployment
- Plan Microsoft 365 integration
- Establish security best practices
