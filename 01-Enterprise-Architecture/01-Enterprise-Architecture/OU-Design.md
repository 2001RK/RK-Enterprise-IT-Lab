# Active Directory Organizational Unit Design

## Objective

Design a scalable Organizational Unit (OU) structure for RK Technologies Pty Ltd that supports centralized management, delegation, and Group Policy deployment.

## Root Domain

rktech.local

## Organizational Units

- Users
- Computers
- Servers
- Service Accounts
- Security Groups
- Admin Accounts

## Department OUs

- Executive
- Human Resources
- Finance
- Sales
- Marketing
- Operations
- Customer Support
- Information Technology

## Naming Standards

### Users

firstname.lastname

### Servers

RK-DC01

RK-FS01

RK-DHCP01

### Security Groups

SG-HR

SG-IT

SG-FIN

### Distribution Groups

DG-AllStaff

DG-HR

## Benefits

- Easier administration
- Simplified Group Policy deployment
- Better security
- Scalability
- Consistent naming standards
