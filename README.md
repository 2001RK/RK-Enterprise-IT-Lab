# RK Enterprise IT Lab

## Project Overview

Welcome to my Enterprise IT Lab.

This repository documents the design, implementation, and management of a simulated enterprise IT environment for **RK Technologies Pty Ltd**, a fictional Australian Managed IT Services and Cybersecurity company.

The goal of this project is to demonstrate practical enterprise-level IT skills through real-world scenarios using Microsoft technologies, networking, cybersecurity, automation, and IT service management.
