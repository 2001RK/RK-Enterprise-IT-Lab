## Business Problem

RK Technologies Pty Ltd is expanding and preparing to onboard 10 new employees.

The existing onboarding process is mostly manual and can take approximately 45 minutes per employee.

The current process includes:

- Receiving onboarding information from HR
- Creating the Active Directory account
- Assigning department access
- Creating Microsoft 365 access
- Configuring email and Teams
- Assigning file permissions
- Preparing the user's computer
- Providing remote access where required

Because the process is manual, there is a risk of delays, inconsistent permissions, and human error.

---

## Business Requirements

The new onboarding process should:

- Reduce manual administrative work
- Standardize account creation
- Assign users to the correct department
- Apply the correct security groups
- Provide required Microsoft 365 services
- Prepare devices for employees
- Reduce onboarding errors
- Improve first-day user experience
- Follow security best practices
